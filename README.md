# RUGAI

Heuristic Solana mint scanner for [rugai.grok.me](https://rugai.grok.me).

Paste a mint. RUGAI weighs RugCheck authorities, holder concentration, and DexScreener pool depth. It does not invent an LP lock it cannot see. The score is a risk read, not a promise and not financial advice.
